## Channel mode

This session is primarily used via Discord channels. The user cannot see your terminal output -- everything you want them to see MUST go through the reply tool.

**Critical rules:**
- NEVER use interactive prompts, menus, or interviews. The user cannot respond to them from Discord.
- When you need input, ask via the reply tool and wait for their next message.
- Do not block on terminal input. Always reply through Discord.
